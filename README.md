# Telegram Apartment Hunter TLV

MVP חינמי לבוט Telegram שמקבל מכם הודעות, פוסטים וקישורים, שומר אותם ומתריע על דירות שמתאימות לחיפוש במרכז תל אביב.

> **חשוב — הטוקן שנשלח קודם בצ׳אט נחשב חשוף.** יש להיכנס ל־BotFather, להפעיל `/revoke` עבור הבוט, להפיק טוקן חדש, ולהכניס אותו **רק** ל־GitHub Actions Secret. אין לכתוב אותו בקוד, בקובץ `.env`, ב־Issue, ב־commit או בצ׳אט.

## מה הבוט עושה

- מקבל טקסט, caption וקישורים (כולל קישורים חבויים בטקסט של Telegram).
- מזהה מחיר של עד 12,000 ₪, 3 חדרים ומעלה ו־2 שירותים ומעלה.
- מזהה את האזורים לב העיר, נווה צדק, כרם התימנים ורוטשילד.
- נותן בונוס לחניה, מרפסת, ממ״ד ומעלית.
- שומר כל מודעה ב־SQLite ומזהה כפילויות לפי קישור נקי או טביעת טקסט.
- שולח התראה מיידית בהרצה רציפה, או במחזור הבא ב־GitHub Actions.
- מעביר מודעה שחסרים בה פרטים ל־`/inbox` לבדיקה ידנית במקום לפסול אותה בטעות.

הבוט **אינו סורק אוטומטית קבוצות פייסבוק פרטיות** ואינו עוקף הרשאות. מעבירים אליו ידנית פוסט או קישור שיש לכם הרשאה לצפות בו. בהמשך אפשר לחבר מקור מורשה באמצעות API מתאים, אם יהיה כזה.

## התקנה חינמית ב־GitHub Actions

זו הדרך הפשוטה ביותר ללא שרת וללא כרטיס אשראי. היא בודקת הודעות בערך כל 5 דקות; GitHub עשוי לעכב הרצות מתוזמנות, ולכן זו אינה מערכת זמן־אמת.

1. ב־BotFather הפעילו `/revoke` לטוקן שנחשף והפיקו טוקן חדש. אל תשלחו אותו לאף אדם או צ׳אט.
2. צרו repository **פרטי** ב־GitHub והעלו אליו את הקבצים בפרויקט הזה. הפרטיות חשובה כי מסד הנתונים מכיל את נוסח המודעות שהעברתם.
3. ב־GitHub פתחו `Settings` → `Secrets and variables` → `Actions` → `New repository secret`.
4. צרו את הסודות הבאים:
   - `TELEGRAM_BOT_TOKEN` — הטוקן החדש מ־BotFather.
5. הפעילו ידנית פעם אחת את `Actions` → `Apartment Hunter Bot` → `Run workflow`. אין צורך לשמור את שם המשתמש של הבוט; Telegram מזהה אותו מתוך הטוקן.
6. שלחו לבוט `/id`, הפעילו שוב את ה־workflow, וקבלו מהבוט את המספר של הצ׳אט.
7. הוסיפו Secret בשם `TELEGRAM_ALLOWED_CHAT_IDS` עם המספר שקיבלתם. לכמה משתמשים, הפרידו בפסיקים. עד שהסוד הזה מוגדר הבוט פתוח לכל מי שמוצא אותו, לכן השלימו את הצעד מיד.
8. שלחו מודעת ניסיון והפעילו את ה־workflow ידנית, או המתינו למחזור המתוזמן הבא.

מסד הנתונים נשמר בקובץ `data/apartments.db` באמצעות commit אוטומטי. ה־workflow מוגדר עם concurrency כדי ששתי הרצות לא יכתבו יחד. אין למחוק את קובץ המסד אם רוצים לשמור היסטוריה ומניעת כפילויות.

## הרצה מקומית רציפה

דרוש Python 3.11 ומעלה. אין חבילות צד שלישי.

ב־macOS אפשר לשמור את הסודות ב־Keychain:

```bash
security add-generic-password -a "$USER" -s apartment-hunter-token -w
```

לאחר מכן הריצו בלי להדפיס את הטוקן למסך:

```bash
export TELEGRAM_BOT_TOKEN="$(security find-generic-password -a "$USER" -s apartment-hunter-token -w)"
export TELEGRAM_ALLOWED_CHAT_IDS="123456789"
PYTHONPATH=src python3 -m apartment_hunter.bot
```

בהפעלה הראשונה אפשר להשאיר זמנית את `TELEGRAM_ALLOWED_CHAT_IDS` ריק, לשלוח `/id`, לעצור מיד את הבוט ולהפעיל מחדש עם המספר שקיבלתם.

## פקודות

- `/start` או `/help` — הוראות קצרות.
- `/id` — מזהה הצ׳אט לצורך רשימת ההרשאות.
- `/criteria` — תנאי החיפוש.
- `/matches` — חמש ההתאמות האחרונות.
- `/inbox` — חמש מודעות שחסרים בהן פרטים.
- `/stats` — מספר ההתאמות, המודעות לבדיקה והפסילות.

## דוגמת הודעה

```text
דירה בלב העיר, 3.5 חדרים, 2 שירותים, 11,800 ש״ח.
מרפסת, מעלית וממ״ד.
https://example.com/listing/123
```

התוצאה תהיה התראת התאמה. ניסוח כמו `ללא חניה` או `בלי מעלית` לא ייספר כבונוס.

## בדיקות

```bash
PYTHONPATH=src python3 -m unittest discover -s tests -v
```

אותן בדיקות רצות אוטומטית בכל push ובכל pull request דרך GitHub Actions.

## מבנה הנתונים והפרטיות

המסד שומר את טקסט המודעה, הקישור, המאפיינים שחולצו, מזהה הצ׳אט ומזהה ההודעה. לכן:

- השתמשו ב־repository פרטי בלבד.
- אל תעבירו לבוט מידע אישי שאין צורך לשמור.
- אל תשתפו את `data/apartments.db`.
- כדי למחוק את המידע, עצרו את ה־workflow ומחקו את מסד הנתונים מהיסטוריית ה־repository בהתאם למדיניות שלכם.

## מגבלות ה־MVP

החילוץ מבוסס על תבניות טקסט ולא על מודל שפה, ולכן ניסוחים חריגים יגיעו ל־`/inbox`. מודעה ללא כל ארבעת פרטי החובה אינה מסומנת כהתאמה. GitHub Actions מתאים ל־MVP חינמי אך לא להתראות מיידיות; להרצה מיידית רציפה אפשר להשתמש במחשב מקומי או להעביר את אותו קוד לשירות אירוח שתומך בתהליך Python מתמשך.
