מי משתמש בלוח

הזמן אנשים לפי אימייל. הם נכנסים עם Google או עם קוד חד־פעמי למייל, ורואים את אותן דירות. מה שאחד שומר או מסתיר מופיע אצל כולם.

בטלפון

פתח את הכתובת הזו בטלפון והתחבר עם אותו אימייל. באייפון: שיתוף ← הוסף למסך הבית.

תוסף פייסבוק ל־Chrome

התוסף קורא את קבוצות הפייסבוק שלך ושולח את הפוסטים לשרת. צור מפתח והדבק אותו בתוסף. יצירת מפתח חדש מבטלת את הקודם.

אבחון

מה הסריקה האחרונה מצאה בכל מקור. אם משהו לא עובד, העתק את הדוח ושלח אותו.
